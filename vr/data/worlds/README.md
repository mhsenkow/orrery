# World data

Authored source of truth for what a world is made of, compiled into frozen runtime modules. Do not edit the compiled files.

## Files

| File | What it is |
|---|---|
| `kinds.json` | Committed kind-resolution histogram. Regenerated by `scripts/worldspace.mjs`. Tests fail if a live audit drifts. |
| `substrates.json` | Surface materials. Compiled by `scripts/substrates.mjs` into `vr/sim/substrates.js`. |
| `cover.json` | Cover kinds (frost, dust, lag, tholin, sulfur, evaporite, rays, mats). Compiled by `scripts/cover.mjs` into `vr/sim/coverTable.js`. |
| `processes.json` | Geomorphic processes. Compiled with `landforms.json` by `scripts/landgram.mjs` into `vr/sim/landGrammar.js`. |
| `landforms.json` | Landforms. Gates are axes and flags, not a name regex. Stamps still paint height. |
| `columns.json` | Column recipes. Compiled by `scripts/columns.mjs` into `vr/sim/columnTable.js`. |

## Adding a substrate

1. Give it an `id` in camelCase and a display `name`.
2. Set `class` (`rock`, `ice`, `organics`, `salt`, `metal`, `fluid`, `envelope`).
3. Fill density (kg/m³), albedo, `k` (W/m/K), `strength` (MPa), `erode` (Earth rain = 1), `rgb`.
4. Ices and volatiles: `meltK`, `boilK`, `tripleK`, `tripleBar`, `LsubJmol`. Optional `criticalK` / `criticalBar`, `convectK` (solid flows above this T).
5. Giants: `noSurface: true` on `envelope`.
6. Tag `measured` / `fitted` / `invented` and write `why` in one sentence.
7. Keep indices 0–7 as the eight Earth rocks (`basalt` … `glacialTill`) so `W.rock` maps without a table.
8. Run `node scripts/substrates.mjs` — the validator refuses duplicate ids, unknown tags, and a missing Earth-rock prefix.

Physics (`phaseAt`, `rheologyAt`, stamping `W.substrate`) lives in `vr/sim/substrateField.js`. The JSON is numbers; the compiler does not invent a cycle.

A nitrogen glacier that was stamped as `sediment` is the kind of error the table exists to end.

## Adding a cover kind

1. Give it an `id` and a display `label`.
2. Set `albedoFine` and `albedoCoarse` (0–1). Fine must be ≥ coarse — grain darkens ice and dust.
3. `rgb`, tag `measured` / `fitted` / `invented`, and a `why` sentence. Optional `cite`.
4. Run `node scripts/cover.mjs`.

Physics (`coverAt`, `stampCover`, grain, weathering) lives in `vr/sim/cover.js`. The JSON is albedos; the compiler does not invent a dust cycle.

## Adding a process or landform

1. Add a process to `processes.json` (`id`, `name`, `rate`, `tag`, `why`). Rate is relative to Earth rain = 1.
2. Add a form to `landforms.json`: `process` must exist, `scaleKm` / `reliefM` / `rgb`, optional `hint`, `needs` keyed on axes and flags (interior, volatile, airless, iceShell, teq, gravity, resurface, tidal) — not a body name.
3. Tag `measured` / `fitted` / `invented` and write `why` in one sentence.
4. Run `node scripts/landgram.mjs`.

Runtime (`landformPalette`, `formAtCell`, `stampLandforms`) lives in `vr/sim/landform.js`. The heightfield is still the 27 stamps. Earth does not stamp. Giants get an empty palette. Exo palettes are marked invented. `craterCounts` is computed from age/resurface/g and is not wired into `stampCraters`.

## Adding a column recipe

1. Add a layer to `columns.json` (`id`, `name`, `rgb`, optional `substrate` from `substrates.json`, tag, why).
2. Add a recipe: `needs` keyed on axes and flags (interior, volatile, airless, iceShell) — not a body name. First match wins.
3. Layer specs take `depthKm`, optional `vary` (`lid` / `ocean`) and `when` (`hpIce` / `clathrate`).
4. Tag `measured` / `fitted` / `invented` and write `why` in one sentence.
5. Run `node scripts/columns.mjs`.

Runtime (`recipeOf`, `columnAt`, `stampColumn`) lives in `vr/sim/columnField.js`. Ice-shell thicknesses follow `W.shellLid` / `W.shellOcean`. Earth does not enter. Giants are `noSurface`. Not a saved per-cell array. Deposition history is not this cut.
