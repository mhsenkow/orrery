# Error codes — quality-400 J20 / J21 · architecture-400 S

Stable `ORR-*` codes from `vr/sim/report.js` `ERROR_CODES` and call sites.
When adding a `report(...)` site, add a row here.

| Code | Meaning | Likely cause | What to do |
|---|---|---|---|
| `ORR-UNCAUGHT-001` | Window `error` | Bug or asset failure | Copy Lab → Diagnostics; file with seed / N |
| `ORR-UNCAUGHT-002` | Unhandled promise rejection | Async path threw | Same |
| `ORR-GPGPU-001` | GPGPU init failed | No float FB / shader compile | Planet runs CPU climate; check Lab climate path |
| `ORR-SAVE-001` | Autosave quota | `localStorage` full | Export a save file; free space |
| `ORR-SAVE-002` | Autosave other failure | Private mode / blocked storage | Export a save; leave private mode |
| `ORR-TEST-001` | Harness self-test | — | Internal |
| `ORR-TEST-DIAG` | Diagnostics probe | — | Internal |
| `ORR-EXPECTED-STORAGE` | Intentional storage swallow | Private mode / quota | Greppable via `expected()`; not a bug |
| `ORR-EXPECTED-URL` | Location / search params | Non-browser / odd URL | Same |
| `ORR-EXPECTED-FOCUS` | `focus()` failed | Detached node | Same |
| `ORR-EXPECTED-LAYOUT` | Local layout not ready | Mid-boot | Same |
| `ORR-EXPECTED-GL` | GL not ready | Scatter LUTs before context | Same |
| `ORR-EXPECTED-LAZY` | Optional chunk failed | Dynamic import / fetch | Same |
| `ORR-EXPECTED-SAVE` | Serialize / field probe | Mid-boot or optional fields | Same |
| `ORR-EXPECTED-MEDIA` | `matchMedia` unavailable | Headless / odd host | Same |
| `ORR-EXPECTED-XR` | XR haptic optional | No haptic actuator | Same |

**J9 / S3–S4:** use `expected(code, detail)` for intentional swallows so they stay greppable.
